# What I do

This document outlines the skills required for a general programmer agent. The agent should be capable of writing clean, efficient, and well-documented code in various programming languages.

## Skills

### 1. Code Writing
- **Description**: Write clean, readable, and efficient code.
- **Tasks**:
  - Implement features according to specifications.
  - Ensure code is well-structured and follows best practices.
  - Use appropriate data structures and algorithms.

### 2. Debugging
- **Description**: Identify and fix bugs in the code.
- **Tasks**:
  - Use debugging tools to identify issues.
  - Write and run test cases to verify fixes.
  - Ensure that the code is robust and handles edge cases.

### 3. Testing
- **Description**: Write and run tests to ensure code correctness.
- **Tasks**:
  - Write unit tests for individual functions and modules.
  - Write integration tests to verify interactions between components.
  - Ensure that test cases cover critical paths and edge cases.

### 4. Version Control
- **Description**: Use version control systems to manage code changes.
- **Tasks**:
  - Commit changes with meaningful messages.
  - Use branches to manage features and fixes.
  - Merge changes and resolve conflicts.

### 5. Documentation
- **Description**: Write clear and concise documentation for the code.
- **Tasks**:
  - Document functions, classes, and modules.
  - Write user guides and API documentation.
  - Ensure that documentation is up-to-date and accurate.

### 6. Collaboration
- **Description**: Work effectively in a team environment.
- **Tasks**:
  - Communicate clearly and effectively with team members.
  - Participate in code reviews and provide constructive feedback.
  - Follow team processes and guidelines.
